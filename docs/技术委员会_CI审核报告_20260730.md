### 详细问题清单

#### P0-CRITICAL: API Server 依赖

**影响**: 22 errors (3 个 Jobs 失败的根因)

**问题描述**:
- `test_full_stack_integration.py` 所有测试需要连接 `localhost:8000`
- CI Pipeline 未在测试前启动 FastAPI 服务器

**修复方案**:
1. 在 CI Pipeline 中添加 API Server 启动步骤
2. 或使用 pytest fixture 启动临时服务器

#### P0-CRITICAL: API 响应格式不匹配

**影响**: 21 tests failed

**问题描述**:
| 测试文件 | 预期字段 | 实际字段 |
|---------|---------|---------|
| `test_test_engine_e2e.py` | `total_tests` | `passed_tests` 等 |
| `test_test_engine_e2e.py` | `workflow_id` | 其他字段 |
| `test_test_engine_e2e.py` | `results` | 其他结构 |

**根因**: API 响应模型重构后，测试未同步更新

#### P1-HIGH: 类定义缺失

**影响**: Governance Tests 收集失败

**问题描述**:
- `_ClassCollector` 类在重构中被移除
- 测试文件 `test_bug_fixes.py` 依赖此类

**修复**: ✅ 已添加 `_ClassCollector` 回 `orchestrator.py`

#### P1-HIGH: 业务逻辑错误

**影响**: 5 tests failed

**问题描述**:
- `test_e2e_business_flow.py::test_full_workflow_governance_approval_flow` - KeyError: 'instance_id'

- `test_e2e_business_flow.py::test_approval_idempotency` - assert False is True

## 四、建议

### 立即修复项

1. **修复 API 响应格式**
   - 对齐 API 输出字段与测试预期
   - 优先修复 `total_tests`, `workflow_id`, `results` 等字段

2. **添加 CI API Server 启动步骤**
   - 在 integration/ui tests 前添加 `uvicorn src.platform.api:app &`
   - 或添加 fixture 管理服务器生命周期

3. **修复业务逻辑错误**
   - `test_e2e_business_flow.py` 中的 4 个失败用例

### 长期改进

1. **测试隔离**: 将需要 API Server 的测试标记为 `integration` 并配置独立 job
2. **契约测试**: 使用 Pact 等工具确保 API 契约一致性
3. **环境管理**: 使用 Testcontainers 或类似工具管理测试依赖

## 三、本次修复的测试问题

### 3.1 权限测试断言更新
- **文件**: `tests/security/test_permissions.py`
- **问题**: 新增 `RUN_TEST` 权限后，管理员权限数量从19变为20，测试员从13变为14
- **修复**: 更新权限数量断言值

### 3.2 工作流引擎测试数据隔离
- **文件**: `tests/platform/test_workflow.py`
- **问题**: 测试执行时包含初始化的默认工作流，导致数量断言失败
- **修复**: 在测试开始时调用 `engine.workflows.clear()` 清空数据

### 3.3 治理审批API Mock完善
- **文件**: `tests/platform/test_api.py`
- **问题**: 审批接口需要先验证审批记录存在性和状态，缺少Mock导致404/400错误
- **修复**: 添加 `approval_manager.get_approval` Mock，并正确设置 `ApprovalStatus.PENDING`

### 3.4 gRPC测试执行路径修复
- **文件**: `apps/web/src/app/workflow/page.tsx`, `apps/web/src/lib/api.ts`
- **问题**: gRPC测试用例执行使用模拟数据（Math.random），未对接后端
- **修复**: 将gRPC路径改为调用 `testApi.execute`，传递service和grpc_method参数
